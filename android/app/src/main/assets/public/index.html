Analysez vos vols FPV long range

Glissez-déposez vos fichiers ici, ou utilisez « Ouvrir des fichiers ». Tout est traité dans votre navigateur : aucun fichier n'est envoyé sur un serveur.

  • Log télémétrie radio (.csv) : carte SD de la radio EdgeTX / OpenTX (dossier LOGS), avec ELRS, Crossfire, FrSky… → trace GPS, batterie, liaison radio.
  • Sous-titres vidéo (.srt), optionnel : enregistrés par les lunettes DJI (O3, O4, FPV) ou Walksnail → qualité de la liaison vidéo.

Astuce : activez les logs dans EdgeTX via une « Fonction spéciale » → Écrire logs SD (0,2 s) sur l'interrupteur d'armement.
